AI Evaluation Glossary

evaluation metrics.

MMLU

Measures broad knowledge and reasoning across 57 subjects, including science, mathematics, history, law, and computer science.

HumanEval

Tests code generation by asking models to write Python functions from natural-language descriptions and checking them with unit tests.

GPQA

Evaluates advanced reasoning using difficult graduate-level questions in science that are designed to challenge both experts and AI models.

GSM8K

Measures multi-step mathematical reasoning using thousands of grade-school word problems that require arithmetic and logical problem solving.

MATH Benchmark

Tests advanced mathematical reasoning with competition-style problems covering algebra, geometry, number theory, probability, and other topics.

HellaSwag

Measures commonsense reasoning by asking a model to choose the most plausible continuation of an everyday situation or event.

ARC

Tests scientific reasoning with grade-school multiple-choice questions from the AI2 Reasoning Challenge, including Easy and Challenge sets.

TruthfulQA

Measures whether a model gives truthful answers and avoids repeating common misconceptions, false beliefs, and misleading information.

Chatbot Arena Elo

Ranks AI models using blind, head-to-head human preferences, where users compare two responses and vote for the better one.

Time To First Token (TTFT)

Measures the delay between sending a request and receiving the model's first output token. Lower values mean faster initial responses.

Tokens Per Second (TPS)

Measures how many output tokens a model generates each second after generation begins. Higher values indicate faster output.

Context Window

The maximum number of tokens a model can process within a single request, including the conversation, instructions, and generated output.

Parameters

The learned numerical values inside a model that shape its behavior and capabilities. More parameters do not always guarantee better performance.

Mixture of Experts (MoE)

An architecture that routes each token to a small subset of specialized expert networks, reducing active computation while supporting large models.

Quantization

Reduces the numerical precision of model weights or activations to lower memory use and speed up inference, sometimes with a small quality trade-off.
